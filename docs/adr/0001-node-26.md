# ADR-0001: Node 26 (Current, not LTS)

**Status:** Accepted · **Date:** 2026-07-29

## Context

Node 26 is the **Current** release line, not Active LTS. Production advice is
normally "use LTS". The project brief explicitly requires Node 26.

Node 26 provides things this project uses directly:

- **Native TypeScript execution.** `.ts` files run with no build step and no
  flag. This removes an entire build pipeline from the repository.
- `node:sqlite` — no native module, no compiler, no `node-gyp`.
- Built-in `fetch`, `util.parseArgs`, and the `node:test` runner.

Together these bring the runtime dependency count to **zero**. There are three
devDependencies and nothing else.

## Decision

Target Node 26 for development and for the daemon. Additionally run CI against
the latest Active LTS to detect gratuitous incompatibility early.

## Consequences

**Positive.** No build step, no bundler, no native modules, no test framework,
no HTTP client, no arg parser. `pnpm install` fetches three packages.

**Negative.** Current lines receive a shorter support window and can ship
breaking changes faster than LTS. Some users will not have Node 26 by default.
`.nvmrc` and the `engines` field make the requirement explicit, and `doctor`
checks it.

**Revisit before v1.0.** Node 26 enters LTS in October 2026. Before tagging
v1.0, either Node 26 must be LTS, or this decision is reopened. If Node 26 were
never to reach LTS, the fallback is to target the then-current LTS and reinstate
a build step — the code is written so nothing but `package.json` scripts and the
`.ts` import extensions would change.

## Alternatives

**Node 22/24 LTS with tsx or a build step.** Safer support window, but adds a
build pipeline and its watch-mode failure modes, for a project whose entire
appeal is that it is simple to audit.

**Bun or Deno.** Both run TypeScript natively and are attractive. Rejected
because macOS audio work benefits from Node's mature `child_process` and stream
behaviour, and because a smaller ecosystem raises the cost for contributors.
